# DocManager - Инструкция для Windows

## 🚀 Быстрый старт

### 1. Первый запуск (на машине-сервере)

1. **Настройте брандмауэр** (один раз):
   - Правой кнопкой на `setup_firewall.bat`
   - Выберите **"Запуск от имени администратора"**
   - Нажмите "Да" в окне UAC
   - Дождитесь сообщения "УСПЕШНО!"

2. **Запустите приложение**:
   - Дважды кликните на `main.exe`
   - Откроется консольное окно с логами
   - Браузер откроется автоматически

### 2. Подключение из локальной сети

**В консоли сервера** вы увидите:
```
============================================================
✓ Сервер запущен успешно!

📍 АДРЕСА ДЛЯ ПОДКЛЮЧЕНИЯ:
   Локально:     http://127.0.0.1:8080
   Из сети:      http://192.168.1.141:8080    ← ЭТОТ АДРЕС

⚠ ЕСЛИ НЕ ПОДКЛЮЧАЕТСЯ ИЗ СЕТИ:
   1. Откройте PowerShell от имени администратора
   2. Выполните команду:
      netsh advfirewall firewall add rule name="DocManager"
            dir=in action=allow protocol=TCP localport=8080

Нажмите Ctrl+C для остановки сервера
============================================================
```

**На других компьютерах**:
1. Откройте браузер (Chrome, Firefox, Edge)
2. Введите адрес: `http://192.168.1.141:8080` (замените на ваш IP)
3. Работайте с документами!

## ❓ Решение проблем

### Проблема: "Не могу подключиться из сети"

**Решение:**
1. Убедитесь что `setup_firewall.bat` был запущен от администратора
2. Проверьте что все компьютеры в одной сети (один роутер)
3. Временно отключите антивирус для теста
4. Проверьте что сервер запущен (консоль открыта)

### Проблема: "Internal Server Error при добавлении документа"

**Решение:**
1. Закройте приложение (Ctrl+C в консоли)
2. Удалите файл `instance\app.db`
3. Запустите `main.exe` снова
4. База данных создастся заново

### Проблема: "Консоль сразу закрывается"

**Решение:**
1. Откройте PowerShell в папке с программой:
   - Shift + Правая кнопка мыши в папке
   - "Открыть окно PowerShell здесь"
2. Запустите: `.\main.exe`
3. Теперь увидите ошибку если она есть

### Проблема: "Где узнать IP адрес?"

**Решение:**
IP адрес **показывается в консоли** при запуске main.exe!

Альтернативно:
1. Win+R → `cmd` → Enter
2. Введите: `ipconfig`
3. Найдите "IPv4-адрес" (например 192.168.1.141)

## 📁 Структура файлов

```
DocManager/
├── main.exe                 ← Запускать это
├── setup_firewall.bat       ← Запустить 1 раз от админа
├── templates/               ← Не трогать
├── static/                  ← Не трогать
├── _internal/               ← Не трогать (библиотеки Python)
├── instance/                ← Создается автоматически
│   └── app.db              ← База данных
└── uploads/                 ← Создается автоматически
    ├── (ваши документы)
    └── trash/               ← Корзина
```

**Можно удалить для сброса:**
- `instance/app.db` - удалить если есть ошибки БД
- `uploads/` - осторожно, тут ваши документы!

**НЕ удалять:**
- `main.exe`, `templates/`, `static/`, `_internal/`

## 🔧 Ручная настройка брандмауэра

Если `setup_firewall.bat` не работает:

1. **Через PowerShell** (от администратора):
   ```powershell
   netsh advfirewall firewall add rule name="DocManager Port 8080" dir=in action=allow protocol=TCP localport=8080
   ```

2. **Через GUI Windows**:
   - Откройте "Брандмауэр Windows в режиме повышенной безопасности"
   - Правила для входящих подключений → Создать правило
   - Тип: Для порта
   - Протокол: TCP, Порт: 8080
   - Действие: Разрешить подключение
   - Профиль: Все
   - Имя: DocManager

## 💡 Советы

- **Консоль не закрывайте** - там логи работы сервера
- **Ctrl+C** для остановки сервера (не просто закрывайте окно)
- **Резервная копия**: Скопируйте папку `uploads/` для сохранения документов
- **Экспорт в Excel**: Есть кнопка экспорта в интерфейсе
